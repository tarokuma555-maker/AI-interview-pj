# ブラウザでの通しの確認(e2e)

公開版を、スマホの縦画面(幅390px)で担当者ログイン・招待リンクから結果・記録の表示まで動かす。

公開入口の移行に伴い、`product.mjs`・`mic-denied.mjs`・`history-retry.mjs` は旧方式専用の履歴として保持し、run.shでは実行しない。旧端末保存の再評価・下書き保持は今回の確認対象外。新方式のマイク拒否・音声/文字面接・保存/再閲覧は `practice-link.mjs` で確認する。

- AI は固定の文面にする(`AI_PROVIDER=mock`)。Claude の API キーは不要。
- Google Cloud の代わりに、模擬サーバー(`fake-google.mjs`)を使う。
- マイクの音は `fixtures/answer.wav`(話してから黙る音声)を使う。模擬サーバーは、聞き取りの結果の最後に「以上です」を付けて返す。

```bash
npm run build                        # リポジトリのルートで
cd e2e && npm install                # 初回だけ(Playwright)
npx playwright install chromium      # 初回だけ(Chromium がない場合)
npm test                             # = bash run.sh
```

| ファイル | 確かめること |
|---|---|
| `release-entry.mjs` | 公開案内・旧招待終了・旧下位画面の転送・privacy・検証画面維持・説明を別タブで開く |
| `product.mjs` | 招待なし・間違った招待 → はじめての案内 → 準備 → 音と声の確認 → 面接(「以上です」で回答が終わる)→ 面接中に移動しようとしたら確認が出る → 結果 → ホーム・記録・応募先(入力の途中で画面を離れても続きから入力できる)・経歴・設定・ヘルプ |
| `mic-denied.mjs` | マイクの使用を断ったとき、直し方を出し、文字で答える面接に切り替えて最後まで進める。文字で答える面接では面接官が「以上です」をお願いしない |
| `history-retry.mjs` | 評価のない練習の記録から結果をまとめ直す。まとめた後も記録の並び順は変わらない |
| `agent-login.mjs` | エージェントのログイン(Supabase がない環境の開発用のログイン)。ログインしていなければログインの画面へ移る、確認コード(全角でも可)でログインできる、読み込み直してもログインしたまま、ログアウト、期限切れのメールのリンク |

| `agent-seekers.mjs` | 求職者・応募先の追加と編集、リンクのコピーと手動コピー、停止・再開、担当外の閲覧拒否、確認付き削除。幅390pxでの表示 |

| `practice-link.mjs` | 別ブラウザで未ログインの招待リンク→マイク拒否→文字面接→結果保存と再読込→再練習、機器確認中の応募先変更・音声回答、回数上限、再送、担当者一覧への反映、リンク停止 |
| `agent-results.mjs` | 求職者がリンクから文字で答える面接を終え、もう1回は途中で閉じる → エージェントが②の「結果を見る」から④の一覧(点数と「途中で終わった練習」)、結果と会話の記録を見る。別のエージェントは結果の URL を開いても見られない |

- 画面は `e2e/out/` に保存する。
- 横にはみ出した画面や、ページのエラーがあれば失敗にする。
- 決まった場所の Chromium を使う場合は `CHROMIUM_PATH` を指定する。
- 声が届いたかどうかや、面接官の声の聞こえ方は、実機で確かめる。


確認用ポート3100/4200が使用中なら終了する。終了時はこの確認で起動した2つのサーバーだけを止める。Supabase の接続設定は確認中だけ空にし、開発用のログイン・保存先を使う。

特定の確認だけを実行する例: `E2E_ONLY=practice-link npm test`（このe2eフォルダー内で実行）。

## 本物の Supabase での確認(段階E)

`supabase-smoke.mjs` は、本物の Supabase につないだ環境(手元の `next start` や本番)で、エージェントのログイン → 求職者と招待リンクの作成 → リンクからの文字の面接と結果 → エージェントの結果の閲覧 → ほかのエージェントから見えないこと、を確かめる。メールは送らない(管理用のキーで作ったログイン用リンクで入る)。確認用のエージェントとデータは最後に消す(`KEEP=1` で残す)。

```bash
BASE_URL=<確かめる URL> NEXT_PUBLIC_SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... node supabase-smoke.mjs
```

本番で実行すると、本物の AI で評価を1回作る(費用がかかる)。

`SMOKE_VOICE=1 E2E_AUDIO_PATH=/絶対パス/日本語音声.wav` を付けると、合成音声をマイク入力として本物の音声認識・音声合成・AI評価を確認する。スマホ実機や人のマイク操作の代わりにはならない。結果の閲覧/再読み込みの記録をDBで確認し、確認用データとその記録だけを最後に削除する。
